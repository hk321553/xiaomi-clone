# 仿小米官网（课程作业）

纯 HTML + CSS + JavaScript 手写的静态站点，无框架、无外部依赖、无需构建步骤，
放到任意静态托管上就能直接打开。

## 本地运行

双击 `index.html` 即可（推荐 Chrome / Edge）。也可以起个静态服务器：

```
npx serve .
```

## 页面结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页（导航 + 轮播 + 产品专区 + 服务 + 页脚） |
| `products.html` | 商城列表页（分类筛选 + 关键词搜索） |
| `product.html` | 商品详情页（按 URL 参数动态渲染） |
| `about.html` | 关于 / 服务页 |
| `css/style.css` | 全站样式 |
| `js/data.js` | 商品数据（12 款商品） |
| `js/main.js` | 交互逻辑（轮播 / 搜索 / 购物车 / 渲染） |

## 主要功能

1. 顶部导航栏 + 搜索框（支持回车搜索）
2. 首页自动轮播图（箭头 + 圆点切换）
3. 商品分类筛选与关键词搜索
4. 商品卡片点击跳转详情页
5. 加入购物车（本地计数 + Toast 提示）
6. 响应式布局（适配手机 / 平板 / 电脑）

## 技术要点

- 采用小米品牌配色，主色 `#ff6700`。
- 全部使用相对路径，可放在任意子目录下正常运行。
- 产品图片使用渐变占位图 + 图标代替，不使用任何真实图片素材。
- 购物车计数保存在浏览器 `localStorage`，无需后端。
